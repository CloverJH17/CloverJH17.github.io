## 📌 Sobre el Proyecto

Este repositorio contiene el código fuente de mi sitio web personal y portafolio profesional, diseñado y desarrollado desde cero para ser desplegado de forma estática, rápida y segura en **GitHub Pages**.

El proyecto refleja un perfil híbrido enfocado en **coordinación de operaciones logísticas**, **proyectos de desarrollo empresarial**, **mentoría formativa STEM (robótica y electricidad)** y **soporte técnico en entornos Linux y gestión de datos**.

---

## ✨ Características Principales

- 🌓 **Tema Oscuro / Claro Persistente:** Conmutador de tema con detección automática de preferencia de sistema (`prefers-color-scheme`) y almacenamiento en `localStorage`.
- 📱 **Diseño 100% Responsivo Mobile-First:** Experiencia optimizada con CSS Grid y Flexbox adaptada para smartphones, tablets y pantallas de escritorio.
- ⚡ **Rendimiento Ultraligero:** Cero dependencias externas pesadas ni frameworks sobrecargados; construido con **Vanilla HTML5, CSS3 y JavaScript ES6+**.
- ♿ **Accesibilidad & Estándares Web:** Marcado semántico, soporte para lectores de pantalla con roles ARIA y contraste optimizado.
- 🔍 **SEO & Open Graph Ready:** Metadatos completos configurados para previsualización enriquecida al compartir en LinkedIn, Twitter/X, Discord y WhatsApp.
- 📋 **Filtros Interactivos:** Sistema fluido para explorar experiencia y proyectos por áreas (*Operaciones, STEM & Educación, Gestión & TI*).
- ✉️ **Copia Rápida al Portapapeles:** Interacción con feedback visual para copiar el correo de contacto con un solo clic.

## 🚀 Instalación y Vista Local

Si deseas clonar y ejecutar este proyecto localmente en tu computadora:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/CloverJH17/CloverJH17.github.io.git
   ```

2. **Acceder a la carpeta del proyecto:**
   ```bash
   cd CloverJH17.github.io
   ```

3. **Abrir en el navegador:**
   - Puedes abrir directamente el archivo `index.html` en tu navegador favorito.
   - O bien, ejecutar una extensión como **Live Server** en VS Code o un servidor local:
     ```bash
     # Usando Python
     python -m http.server 3000
     
     # Usando Node (npx)
     npx serve .
     ```
